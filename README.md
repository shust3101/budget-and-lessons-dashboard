# budget-and-lessons-dashboard
Excel Analytics Project — Budget & Lessons Dashboards
This project contains two analytical dashboards built in Excel:
a Budget Dashboard for personal finance tracking and a Lessons Dashboard for managing lesson packages, student activity, and income.

The goal of the project is to demonstrate skills in data analysis, dashboard design, KPI logic, and Excel automation.

📊 Dashboards Included
1. Budget Dashboard
A clean and structured dashboard that visualizes monthly financial activity.

Key Features:

Total Income

Total Expenses

Savings

Final Balance

Pie chart: Expenses by Category

Bar chart: Income vs Expenses

Professional layout with KPI cards and consistent formatting

2. Lessons Dashboard
A dashboard designed to track lesson packages, student activity, and revenue.

Key Features:

Active Students

Lessons Completed

Packages Purchased

Income from Lessons

Bar chart: Lessons Completed per Student

Pie chart: Income by Lesson Type (Package vs Non‑Package)

Clear structure for managing lesson‑based income

📁 Workbook Structure
The Excel file contains the following sheets:

Budget Overview — raw monthly budget data

Expenses — detailed expense table

Lessons Data — student lessons, packages, payments

Budget Dashboard — financial visualization

Lessons Dashboard — lesson management visualization

This structure separates data from dashboards and follows best practices for analytical Excel projects.

🛠 Skills Demonstrated
Dashboard design (KPI cards, layout, color consistency)

Data cleaning and structuring

Lookup formulas and conditional logic

SUMIFS / COUNTIFS for KPI calculations

Chart creation and formatting

Data storytelling through visualization

Professional Excel file organization

Portfolio‑ready documentation
